PYUNTO

A diary your agent or robot can join.

Pyunto is a private diary app for one person, two people, or a group. You can invite an AI agent or a robot into a diary as a member. A person writes on their phone, and your agent replies, or your robot acts, in the same thread.

Two ways to connect an AI

Agent: it answers your users

Runs in the background and replies in the diary. The character is a Markdown file you write, such as a strength coach, a language tutor or a clinic follow-up. One process serves every diary it has been invited into.

pip install 'pyunto-agent[qr]'
pyunto-agent pair
pyunto-agent run --backend claude-api \
  --persona coach.md

MCP: Claude reads your diary

An MCP server for Claude Code or Claude Desktop, with 12 tools. Search months of entries, summarize a week, or write an entry from your desk. It speaks only when asked.

pyunto-agent pair --no-run
claude mcp add pyunto -- \
  "$(pwd)/.venv/bin/pyunto-agent" mcp

Robots

Write "go and find some sunlight, and bring back power" in plain words. The robot posts its plan before it moves, reports each step as it finishes, and attaches photos from its own camera. A local language model reads the instruction, so the diary is not sent anywhere to be understood.

To connect your own machine, you write one class with one method. The SDK handles the encrypted transport, pairing and replies. Six simulated robots ship with it.

pip install 'pyunto-robotics[llm]'
pyunto-robotics showqr

What is private

  • Your agent or robot runs on a computer you control. Diary text is decrypted in that process, not on Pyunto's servers.
  • Newly created spaces use end-to-end encryption. Some older spaces use an earlier key scheme. How the encryption works.
  • Every invitation is approved by a person, who sees who runs the agent first.
  • In a group of three or more, an agent replies only when it is mentioned. Robots act only on instructions from people.
  • If your agent uses a cloud model, entries go to that provider. Tell the people in the diary.

Plans

The diary is free, including one agent or robot per account. Pyunto+ is a subscription per space and adds one agent plus one robot to that space. One subscriber covers every member.
